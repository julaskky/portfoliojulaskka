JULIUS OLANIYAN PORTFOLIO — PHASE 1

This is the React homepage source for a Vite project. PHP and MySQL will be connected in a later phase.

1. Open Command Prompt in the folder where you keep your projects.
2. Create the React project if you have not already:
   npm create vite@latest julius-portfolio -- --template react
3. Enter the project and install dependencies:
   cd julius-portfolio
   npm install
4. Copy the files from this package's src folder into the new project's src folder, replacing App.jsx, App.css, index.css, and main.jsx.
5. Start the development server:
   npm run dev
6. Open the local URL shown by Vite, usually http://localhost:5173.

CUSTOMISE BEFORE PUBLISHING:
- In src/App.jsx, replace hello@yourdomain.com with your real public contact email.
- Review the sample project descriptions and update them to reflect current status and links.
- The name and profile details are starter content and can be edited directly in App.jsx.

This phase uses React only. No database or PHP endpoint is required yet. Keep this project separate from Global Job Finder unless you deliberately want to combine them.
